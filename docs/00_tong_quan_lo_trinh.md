## 🏗️ 2. Ba trụ cột thách thức lớn nhất của Tiếng Nga và giải pháp

```
                           +-------------------------------------+
                           |      3 TRỤ CỘT TIẾNG NGA           |
                           +-------------------------------------+
                                   /           |           \
                                  /            |            \
                                 v             v             v
       +----------------------------+  +---------------+  +-------------------------------+
       | 1. HỆ THỐNG 6 CÁCH         |  | 2. THỂ ĐỘNG TỪ |  | 3. ĐỘNG TỪ CHUYỂN ĐỘNG        |
       | (Падежная система)         |  | (Вид глагола) |  | (Глаголы движения)            |
       | Biến đổi đuôi danh từ,    |  | Cặp НСВ - СВ   |  | Cặp định hướng - vô hướng     |
       | tính từ, đại từ, số từ.    |  | Quá trình vs   |  | (идти/ходить, ехать/ездить)   |
       | Trả lời các câu hỏi:      |  | Kết quả/       |  | và hệ thống tiền tố không gian|
       | Ai? Cái gì? Ở đâu?        |  | Hoàn tất       |  | (в-, вы-, при-, у-, под-... ) |
       | Bằng cái gì? Cho ai?       |  |               |  |                               |
       +----------------------------+  +---------------+  +-------------------------------+
```

### 1. Hệ thống 6 Cách (Падежи):
- **Cách 1 (Именительный - Nominative):** Chủ ngữ, trả lời câu hỏi *Кто? Что?*
- **Cách 2 (Родительный - Genitive):** Sở hữu, số lượng, phủ định *нет*, trả lời *Кого? Чего? Откуда? Сколько?*
- **Cách 3 (Дательный - Dative):** Đối tượng tiếp nhận, tuổi tác, trạng thái, trả lời *Кому? Чему?*
- **Cách 4 (Винительный - Accusative):** Tân ngữ trực tiếp, đích đến hướng tới, trả lời *Кого? Что? Куда?*
- **Cách 5 (Творительный - Instrumental):** Công cụ, phương tiện, đi cùng ai (*c* + C5), nghề nghiệp, trả lời *Кем? Чем? С кем? С чем?*
- **Cách 6 (Предложный - Prepositional):** Địa điểm (*в/на* + C6), chủ đề suy nghĩ/nói về (*о* + C6), trả lời *О ком? О чём? Где?*

### 2. Thể động từ (Вид глагола):
Mỗi hành động trong tiếng Nga thường được diễn đạt qua **Cặp thể (Видовая пара)**:
- **Chưa hoàn thành thể (Несовершенный вид - НСВ):** Nhấn mạnh quá trình, hành động lặp đi lặp lại thường xuyên, hoặc chỉ gọi tên sự việc đơn thuần.
- **Hoàn thành thể (Совершенный вид - СВ):** Nhấn mạnh kết quả đã hoàn thành trọn vẹn, hành động diễn ra một lần duy nhất, hoặc sự chuyển biến trạng thái.

### 3. Động từ chuyển động (Глаголы движения):
- Phân biệt chuyển động một chiều, xác định hướng tại một thời điểm (*идти, ехать, бежать, лететь, плыть, нести...*) với chuyển động đa chiều, khứ hồi hoặc năng lực tổng quát (*ходить, ездить, бегать, летать, плавать, носить...*).
- Khi thêm các tiền tố (*при-, у-, в-, вы-, под-, от-, пере-, за-...*), chúng kết hợp cùng hệ thống thể để mô tả không gian chuyển động chuẩn xác tuyệt đối.

## 📅 3. Lịch trình và Phương pháp học khuyến nghị hàng ngày

1. **Giai đoạn tiếp nhận (30 phút):** Nghe file Audio đi kèm sách (*Поехали 1.1 TB/WB mp3* hoặc *Audio Đường đến nước Nga*), đọc to theo ngữ điệu để làm quen với ngữ điệu chuẩn (Интонационные конструкции: ИК-1 đến ИК-5).
2. **Giai đoạn ngữ pháp nòng cốt (45 phút):** Nắm chắc 1 chuyên đề quy tắc biến cách hoặc chia động từ. Lập sơ đồ tư duy cho đuôi từ.
3. **Giai đoạn thực hành ứng dụng (45 phút):** 
   - Làm bài tập trắc nghiệm và điền đuôi từ.
   - Luyện tập trên nền tảng Web học tiếng Nga (thực hiện kiểm tra và xuất kết quả CSV để lưu nhật ký tiến độ).
4. **Giai đoạn đọc mở rộng & tích lũy từ vựng (20 phút):** Đọc các mẩu hội thoại ngắn hoặc trích đoạn trong *116 bài đọc, học và luyện*.
