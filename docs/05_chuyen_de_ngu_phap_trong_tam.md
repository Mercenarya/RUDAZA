## 🏛️ TRỤ CỘT 1: HỆ THỐNG BIẾN CÁCH TOÀN DIỆN (6 ПАДЕЖЕЙ)

### Bảng tổng hợp Đuôi Danh từ số ít (Единственное число)

| Cách | Giống đực (Мужской) | Giống cái (Женский) | Giống trung (Средний) |
| :--- | :--- | :--- | :--- |
| **Cách 1 (Кто? Что?)** | gốc phụ âm / -й / -ь (*студент, музей, словарь*) | -а / -я / -ь (*книга, песня, ночь*) | -о / -е / -ие (*окно, море, здание*) |
| **Cách 2 (Кого? Чего?)** | **-а / -я** (*студента, музея, словаря*) | **-ы / -и** (*книги, песни, ночи*) | **-а / -я** (*окна, моря, здания*) |
| **Cách 3 (Кому? Чему?)** | **-у / -ю** (*студенту, музею, словарю*) | **-е / -и** (*книге, песне, ночи*) | **-у / -ю** (*окну, морю, зданию*) |
| **Cách 4 (Кого? Что?)** | Bất động vật = C1; Động vật = C2 | **-у / -ю / -ь** (*книгу, песню, ночь*) | Giữ nguyên như Cách 1 (*окно, море*) |
| **Cách 5 (Кем? Чем?)** | **-ом / -ем** (*студентом, музеем, словарём*) | **-ой (-ей) / -ью** (*книгой, песней, ночью*)| **-ом / -ем** (*окном, морем, зданием*) |
| **Cách 6 (О ком? О чём?)**| **-е / -и** (*о студенте, о музее, о словаре/гении*)| **-е / -и** (*о книге, о песне, о здании/ночи*)| **-е / -и** (*об окне, о море, о здании*) |

## ⚡ TRỤ CỘT 2: CHUYÊN ĐỀ THỂ ĐỘNG TỪ (ВИД ГЛАГОЛА)

### Các mô hình tạo cặp thể thông dụng:
1. **Thêm tiền tố vào động từ НСВ để tạo СВ:**
   - *читать -> **про**читать*
   - *писать -> **на**писать*
   - *делать -> **с**делать*
   - *учить -> **вы**учить*
2. **Thay đổi hậu tố bên trong gốc từ:**
   - *реш**а**ть (НСВ) -> реш**и**ть (СВ)*
   - *получать (НСВ) -> получить (СВ)*
   - *открыв**а**ть (НСВ) -> откр**ы**ть (СВ)*
3. **Đổi vị trí trọng âm:**
   - *разрез**а́**ть (НСВ) -> разр**е́**зать (СВ)*
4. **Cặp thể khác gốc hoàn toàn (Супплетивизм):**
   - *говорить (НСВ) -> сказать (СВ)*
   - *брать (НСВ) -> взять (СВ)*
   - *класть (НСВ) -> положить (СВ)*
   - *ловить (НСВ) -> поймать (СВ)*

## 🚶 TRỤ CỘT 3: CHUYÊN ĐỀ ĐỘNG TỪ CHUYỂN ĐỘNG (ГЛАГОЛЫ ДВИЖЕНИЯ)

### Phân biệt 14 cặp động từ chuyển động cơ bản:
1. *идти - ходить* (đi bộ)
2. *ехать - ездить* (đi xe)
3. *бежать - бегать* (chạy)
4. *лететь - летать* (bay)
5. *плыть - плавать* (bơi, đi thuyền)
6. *нести - носить* (mang, xách bằng tay)
7. *везти - возить* (chở bằng phương tiện)
8. *вести - водить* (dẫn dắt, lái xe)
9. *лезть - лазить* (leo trèo)
10. *ползти - ползать* (bò, trườn)
11. *брести - бродить* (lang thang)
12. *тащить - таскать* (kéo lê)
13. *катить - катать* (lăn, đẩy xe lăn)
14. *гнать - гонять* (xua đuổi)
